# UnEarthed

Objectives Met:
    -Created a server using Node and Express
    -Created routes and request handlers using Express
    -Responded to a GET request by serving static HTML documents
    -Served an appropriate document in the case of no matching route
    -Organized server files appropriately

Features:
    -The web app uses only HTML, CSS, and JavaScript without a frontend framework.
    -The web app displays the title and logo of Unearthed.
    -The web app displays a list of gifts that have been submitted, including at least the name, price point, audience, and image.
    -The user can click on each item in the list to see a detail view of it, including all database fields.
    -The web app serves an appropriate 404 page when no matching route is defined.
